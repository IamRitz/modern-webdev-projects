# LeadTracker - A Chrome Extension

LeadTracker is a Chrome extension designed to help users track and
manage their leads efficiently. It provides a user-friendly interface
for organizing and monitoring potential clients, making it easier to
follow up and convert leads into customers.

From Scrimba Course

## How to Use
1. Install the LeadTracker extension from the Chrome Web Store.
2. Click on the LeadTracker icon in the Chrome toolbar to open the extension.
3. Use the interface to add new leads by typing, add leads from the current active tab, and Delete leads as
   needed (Currently all leads are stored in localStorage, so they will persist across sessions.)
